# Source

The production implementation belongs here and should be MNCS-language first.

This foundation merge intentionally does not add pretend implementation code. The next implementation pass should establish the smallest executable MNCS project that can perform deterministic concurrent corpus indexing and should record every real language gap encountered.

Expected early modules include conceptual areas for:

- source snapshots,
- work scheduling,
- extraction/parsing,
- normalized records,
- canonical merge,
- snapshot publication,
- query execution.

Module boundaries should emerge from actual MNCS-language pressure rather than being frozen prematurely by scaffolding.
